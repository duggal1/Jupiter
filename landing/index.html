Jupiter

Mac Storage is lying to you. Jupiter shows the truth.

The junk macOS hides from Settings is right there — caches, Xcode bloat, and the dev folders nobody mentions: node_modules, .build, target, dist — often 30–40 GB. Jupiter measures it in real allocated bytes, badges it honestly, and removes it in one clean. No ads. No upsells. No lag.

Honest badges. No garbage.

  • Safe — regenerates automatically. Loses nothing.
  • Okay — with limits. Dev builds rebuild with npm install / swift build. Auto-Clean takes these.
  • Risky — deletes user data. Browser caches wipe your whole Chrome profile (history, logins, session). Never auto-selected.
